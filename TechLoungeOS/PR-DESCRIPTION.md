# Add standalone Windows ISO customisation and verified setup USB creation

TechLoungeOS Builder imports a Windows11 x64 ISO, services a selected edition with DISM and carries the same choices through to ISO, USB or both. Modified-image baselines protect inherited component removals, service/policy/default-user settings and WinPE tools. Existing downloads are retained unless the app user chooses and confirms staged replacement. The original TechLoungeTweaks release remains separate.

The five-step interface covers components, icon-backed app search/recommendations, wallpaper/locale and final output. Generated media includes the redesigned WinPE launcher/account wizard, normal Microsoft365 deployment, Edge, runtimes, Store/Xbox restoration, HatchZip and the reviewed Tweaks integration. Long Builder-owned installers wait for the first desktop, retain successes and expose progress/retry. Hardware-specific drivers are detected on the installed PC; Boot Optimizer waits for required apps. User-requested UAC, Internet-zone and legacy SMB defaults are documented. No activation launcher or blanket antivirus exception is deployed.

Supported Windows upgrades require exact Microsoft package identities, source prerequisites, a healthy image and reviewed migrations. The Ghost9457 route and standard8037 route are separate; unknown changes, lost apps, restored removed security payloads or unexpected task data stop export. Three measured internal metadata values may migrate only while all other affected settings match. Exact full task data remains required even when offline task-definition folders are empty.
